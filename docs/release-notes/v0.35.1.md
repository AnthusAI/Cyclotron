# v0.35.1

Standing Cyclotron publication targets no longer have lifetime request, daily
request, or total-item quotas. Older trusted target configurations may retain
`requestCeiling` or `maxItems`; these fields are ignored for standing targets.

Provider attempts continue to be recorded in the shared request ledger, cached
decisions remain reusable without another model call, and existing bounded
work units, payload checks, retries, concurrency controls, and operational
metering remain in place. Non-standing evaluation runs keep their reviewed
per-open request budgets.
