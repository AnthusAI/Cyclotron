# Cyclotron

Editorial intelligence for publications. A cyclotron learns a recurring editorial decision from reviewer feedback and steers itself between reviews.

- [Using Cyclotron](using-cyclotron.md): set up and run a cyclotron for a decision that recurs.
- [Embed a cyclotron in an application](embedding.md): open a store, run cycles, and show reviewers what it is doing.
- [Glossary](glossary.md): one word per concept, used across the engine, console and docs.
- [Hosted publications](hosted-publications.md) and [publication deployment contract](publication-deployment-contract.md): how a hosted cyclotron is deployed.
- [Cyclotron is a general decision engine](general-decision-engine.md): design for review, renaming the publication-specific contract, routes and lab copy to bindings and standing runs.
